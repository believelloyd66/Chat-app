# CHATS — Modern Messaging Demo

A polished, mobile-first chat interface demo.

## Features
- Chat list with avatars, online status, unread badges
- Full conversation view with message bubbles
- Send messages (with simulated replies)
- Smooth slide transitions
- Live clock, responsive design

## How to run
Just open `index.html` in any modern browser.
No build step required.

## Tech
- HTML / CSS / Vanilla JS
- Bootstrap 5.3 (CDN)
- Bootstrap Icons

## Preview
Best viewed on mobile or with browser width ≤ 420px.
